## 5. 文档变更流程

1. **先改文档再写码**：新接口 → 先加 `04` A2 表；新字段 → 先改 `03` DDL；新规则 → 先改 `01`。
2. **改一处，查全链**：改表名要 grep 全目录；改版本要同步 `02` §2 与 §10。
3. **决策留痕**：任何与文档不同的实现，必须写进 `02` §10 偏离登记（日期/文档值/实际值/原因/影响）。
4. **术语统一**：新术语先写 `01` §3，代码、UI、文档用同一个词。
5. **不要新开文档**：`01`–`06` 是规范，`07` 是操作手册；除此之外不再拆，避免事实分裂。
